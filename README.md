## 📖 The Story Behind Quolix

As large language models and autonomous AI agents become foundational to modern software, developers face mounting challenges in latency, model routing, safety guardrails, and cost management. **Quolix AI** is the unified intelligence layer that sits between production applications and AI foundation models.

The Quolix web platform is designed with developer-first aesthetics: dark mode obsidian backgrounds, crisp monospaced typography, interactive command palettes, 3D geometric visualizations, and live playground demos.

---

## ✨ Key Functions & Experience

### 1. Global Interactive Command Palette (`Cmd + K`)
- Instant keyboard navigation across docs, pricing, playground, and API key management.
- Fuzzy-matching search with keyboard navigation and action triggers.

### 2. Interactive AI Playground Modal
- **Live Inference Simulation**: Test prompt payloads with real-time streaming tokens.
- **Multi-Model Benchmark**: Compare token cost, latency, and quality across Claude 3.5, GPT-4o, and Llama 3.3.

### 3. Dynamic 3D Geometric Visualizers
- Mathematical wireframe 3D renderings including animated tetrahedrons, dynamic spheres, and wave harmonic curves.

### 4. Enterprise Infrastructure & Routing Telemetry
- Global edge routing map with latency counters across US-East, Frankfurt, Tokyo, and São Paulo.
- Real-time uptime telemetry and failover benchmark indicators.

### 5. Flexible Billing Calculator
- Dynamic pricing tier matrix with instant monthly vs. annual savings toggles.
- Enterprise custom quote generator with immediate contact callbacks.

## 🚀 Quick Start & Local Development

```bash
# Clone the repository
git clone https://github.com/orivojka-eng/quolix.git

# Navigate to directory
cd quolix

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev
```
